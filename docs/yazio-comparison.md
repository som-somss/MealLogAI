# YAZIO 비교와 MealLog AI 보완 순서

확인일: 2026-11-08. YAZIO 공식 안내와 MealLog AI의 현재 소스를 비교했습니다. YAZIO 기능은 무료·Pro 및 플랫폼에 따라 차이가 있으며, 아래 비교는 직접 앱 전체를 사용해 평가한 결과가 아닙니다.

| 영역 | YAZIO 공식 안내 | MealLog AI 상태와 다음 작업 |
| --- | --- | --- |
| 영양 목표·진행률 | 열량 목표와 탄수화물·단백질·지방 비율 조절 [1] | 이번에 세 영양소의 g 목표·남은 양·초과량·진행 막대 추가. 기존 단백질 목표를 AI 코치와 공유. 비율 기반 설정·날짜별 목표 이력은 후속 범위. |
| 음식 기록 | 사진 추정, 바코드, 최근·자주 먹는 음식 [2][3] | 사진·바코드·영양표·수동 검색·최근 음식·내 조합이 이미 있음. 인식 정확도 우열은 측정하지 않음. |
| 레시피와 인분 | 여러 인분, 조리 단계, 인분 또는 g으로 기록 [4] | 조합과 재료별 양 편집은 있음. 총 조리량·인분 환산·조리 단계 없음. 다음 우선순위: 저장 조합을 2인분 만들어 0.5인분 먹는 경우를 정확하게 기록. |
| 식단 계획·장보기 | Pro에서 미래 식사 계획, 레시피와 장보기 목록 [2] | 날짜별 기록은 있으나, 예정 식단과 실제 섭취를 구분하는 흐름 및 장보기 집계는 없음. 계획을 섭취량에 미리 더하지 않는 구조부터 필요. |
| 상세 영양 | Pro에서 식이섬유·당·소금 등 상세 분석 [2] | 주로 열량·탄수화물·단백질·지방을 저장. 출처별 단위·누락 여부를 유지하는 식이섬유·당·나트륨 확장이 필요. |
| 건강 앱 연결 | Pro에서 지원되는 활동 서비스와 자동 연결 [2] | 물·체중·운동·수동 걸음·아이폰 단축어는 있음. 네이티브 건강 플랫폼 자동 연동은 없음. |

## 우선순위

1. **영양 목표·진행률 — 이번 구현.** 사용자가 선택한 우선순위. 홈에서 확인하고 설정에서 다시 접근. 계정 저장, 단백질 목표 공유, 누락 영양소 비교 보류.
2. **조합의 인분·조리량 계산.** 현재 사용하는 시오콘부볶음밥 같은 집밥 조합을 여러 인분으로 만들고 일부만 먹는 흐름. 재료 합계와 먹은 양을 구분하고 기존 조합·식사 편집과 함께 검증.
3. **예정 식단·장보기.** 계획 상태, 실제 섭취 전환, 재료 단위 정규화와 중복 합산.
4. **상세 영양소.** 값이 없는 음식을 0으로 간주하지 않고 데이터 출처·기준량·단위를 보존.
5. **자동 활동 연동 및 선택형 알림.** 모바일 플랫폼·권한·중복 기록 처리를 설계한 뒤 구현. 단식 기능은 별도 수요 확인 후 진행.

MealLog AI는 한국 음식 검색과 실제 식사·저장 조합을 대화로 함께 수정하는 기존 흐름을 유지하며 보완합니다. 경쟁 앱이 이 기능을 지원하지 않는다고 단정하지 않습니다.

## 이번 목표 기능의 범위

- `홈 → 영양 목표 → 목표 설정`에서 직접 입력. 빈칸은 목표 미설정이며 권장량을 임의로 채우지 않음.
- 선택 날짜의 식사에서 영양소를 합산. 남은 양, 목표 도달, 초과량을 구분. 초과 막대는 100%에서 멈추되 실제 기록량은 표시.
- 미입력 영양소는 0으로 취급하지 않고 해당 영양소 비교만 보류. 기록이 없는 날은 섭취하지 않은 날로 단정하지 않음.
- 현재 목표가 과거 날짜에도 적용됨. 당시 목표 이력 및 열량 목표와 영양소 비율의 자동 환산은 아직 없음.
- 기존 `ai_coach_settings`에 nullable `carbs_goal`, `fat_goal`만 추가. 기존 `protein_goal`, AI 사용·기억 설정, 식사·조합은 유지.
- 계정 변경 시 화면 초기화, 저장 실패 시 입력 유지, 다른 화면에서 목표가 바뀌면 재확인 요청.
