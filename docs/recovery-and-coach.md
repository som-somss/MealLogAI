## 확인한 문제와 수정

기존 `previousIntent`는 음식명과 질문 유형만 반환했습니다. `과메기 100g 먹으면?` 다음에
`그럼 반만 먹으면?`을 보내면 양이 `null`이 되어 50g 계산으로 연결되지 않았습니다.
`과메기 어느 정도 먹어야 할까?`도 기본 분류에서는 일반 질문으로 처리됐습니다.

현재는 기존 대화 메타데이터에 음식명, 명시한 양과 단위, 분석 날짜, 선택 날짜를 보관합니다.
명확한 후속 양 변경은 서버 코드로 처리하고 영양값은 기존 음식 DB를 이용해 계산합니다.
기준 양이 없는 비율 질문은 확인 질문으로 답하며, 새 음식이나 날짜 변경은 이전 양을 가져오지 않습니다.
이전 형식의 대화는 바로 앞 사용자 질문만 참고하고, 다른 주제를 건너뛰어 옛 음식을 찾지 않습니다.

`meallog_coach_save` 함수 정의를 읽어 기존 JSONB 메타데이터를 그대로 저장하는 구조임을 확인했습니다.
DB 함수·테이블·식단 기록은 변경하지 않았습니다.

## 운영 반영 시 확인
