# 대화에서 내 조합 다시 기록하기 · 2026-11-09

## 동작

`AI 코치 → 저장한 조합 이름·날짜·끼니·양 요청 → 기록할 내용 확인 → 재료별 양/개인 분량 확인 → 식사 저장 전 확인 → 확인하고 식사 저장`으로 이어집니다. 대화 응답은 초안을 준비했다고만 안내하며, 실제 기록은 기존 `meallog_record_combination` RPC의 성공과 서버 재조회를 확인한 뒤 표시합니다.

지원 예: “저장한 시오콘부볶음밥을 오늘 점심으로 기록해줘”, “시오콘부볶음밥 0.5인분을 오늘 점심으로 기록해줘”, “시오콘부볶음밥 200g을 어제 저녁으로 기록해줘”. 전체 비율(절반, 1/4, %, 배), 인분, 완성 g을 지원합니다. 날짜를 생략하면 선택한 분석 날짜를 명시해 보여 줍니다. 인분/g의 전체 기준이 없으면 설정 안내를 하고 추정하지 않습니다.

새 `coach-record.js`가 명확한 요청을 기존 AI 해석보다 먼저 처리합니다. 사용자의 JWT와 계정 조건으로 승인된 조합만 조회하고 기존 `combination-record-core.js`로 계산합니다. 이 흐름은 외부 생성형 AI나 유료 AI 예약을 호출하지 않습니다. 대화 초안은 기존 `ai_coach_messages.metadata`에 저장하며 DB 스키마/권한/인증 설정을 변경하지 않았습니다.

초안은 요청 ID, 조합 ID와 revision, 날짜·끼니·양을 유지합니다. 다시 열 때 최신 조합의 revision을 비교하고, 이미 저장된 같은 요청 ID의 식사가 있으면 현재 서버 식사를 보여 줍니다. 다른 탭에서 같은 초안을 열어도 동일 요청 ID로 한 번만 저장합니다. 과거 식사나 기본 조합을 소급 변경하지 않습니다. 계정 변경 뒤 오래된 대화 버튼은 실행되지 않습니다.
