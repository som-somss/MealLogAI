## 발견하여 수정한 문제

- 후속 질문에서 음식명만 남고 양이 사라지던 문제를 수정했습니다.
- 실제 모델 응답에 숫자가 포함되면 답변 전체를 거부하던 문제를 확인했습니다. API 연결과 앱 이용 한도 문제는 아니었습니다.
- AI 설명 입력의 수치를 가리고, 숫자나 수치 자리표시자가 들어간 문장은 통째로 제외합니다. 나머지 설명이 없을 때만 한 번 다시 작성합니다. 검증된 계산값은 서버가 별도로 표시합니다.
- 식사 기록 누락 등의 주의사항도 모델에 전달합니다.
- 실패 단계와 제한된 오류 코드만 진단 메타데이터에 저장합니다. 원문 질문·모델 오류 본문·API 키를 진단 정보에 기록하지 않습니다.
- Node 런타임을 `24.x`로 고정했습니다.
