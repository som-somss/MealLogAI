아이폰 걸음 연결

단축어로 오늘의 움직임을 가져와요

단축어를 실행할 때 오늘 걸음 수를 가져와요. 날짜와 걸음 수만 내 계정으로 전송하며, 다른 건강 정보는 읽거나 보내지 않아요. PC 수동 입력도 계속 사용할 수 있어요.

키는 지금 한 번만 보여요. 잃어버리면 새로 만드세요. 새 키를 만들면 이전 연결은 해제돼요. 90일 후 만료되며, 기록 초기화 시에도 연결이 해제돼요.

아이폰 단축어 설정 방법

처음 한 번만 아래 순서로 만들어요. 실제 건강 데이터 접근 허용은 아이폰에서 직접 진행해 주세요.

  1. 아이폰의 단축어 앱에서 새 단축어를 만들고 MealLogAI 걸음 보내기로 이름을 정해요.
  2. 현재 날짜를 추가하고 변수 이름을 실행 날짜로 정해요. 같은 날짜를 다음 단계들에 사용해요.
  3. 건강 샘플 찾기를 추가해 유형: 걸음, 시작 날짜: 오늘로 설정해요. 소스는 내 아이폰 하나만 선택하고, 제한은 꺼 주세요. 아이폰·워치를 동시에 합산하지 마세요.
  4. 건강 샘플의 세부사항 가져오기에서 값을 가져온 다음, 통계 계산을 합계로 설정해요. 이 결과가 걸음 합계예요. 결과가 없다면 전송하지 않고 종료해 주세요.
  5. 2번의 실행 날짜를 날짜 포맷으로 변환하고, 사용자 설정 포맷을 yyyy-MM-dd로 해요. 한국 시간 기준 오늘 날짜로 보내 주세요.
  6. URL 콘텐츠 가져오기를 추가하고 아래 주소를 넣어요. 방법은 POST, 요청 본문은 JSON으로 설정해요.
https://meallogai.vercel.app/api/shortcut-steps

헤더 2개

AuthorizationBearer 연결키
Content-Typeapplication/json

Bearer 뒤에 공백 하나를 두고 위에서 복사한 연결 키를 붙여 넣어요. 계정 비밀번호는 넣지 않아요.

JSON 본문 2개 · 이름은 date와 steps

빈 이름의 JSON 항목은 지워 주세요. 날짜 뒤 줄바꿈과 숫자 텍스트는 서버가 정리해요.

date · 텍스트포맷한 실행 날짜 변수
steps · 숫자 또는 텍스트걸음 합계 변수 · 1002 또는 "1002" 모두 가능
  1. 마지막에 결과 보기를 추가하고 실행해요. 처음에는 건강 앱의 걸음 읽기와 MealLogAI 전송을 허용해 주세요. ok: true가 나오면 운동 탭에서 새로고침해요.
  2. 잘 전달되는 것을 확인한 뒤 단축어의 자동화 → 특정 시간에서 이 단축어를 실행하도록 정할 수 있어요. 처음에는 직접 실행으로 확인해 주세요.

기기·iOS 버전에 따라 동작 이름이 조금 다를 수 있어요. 잠금 상태에서는 건강 데이터에 접근하지 못할 수 있고, 건강 앱 전체 수치와 한 기기 합계는 다를 수 있어요. 실시간 연동이 아니며, 전송 때마다 같은 날의 총걸음 수 중 큰 값을 유지해 중복으로 더하지 않아요.
