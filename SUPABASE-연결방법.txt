MealLogAI Growth v4 - Supabase 연결

1. supabase-config.js 파일을 메모장으로 엽니다.
2. PASTE_YOUR_SUPABASE_PUBLISHABLE_KEY_HERE 부분만 Supabase의 Publishable key(sb_publishable_...)로 바꿉니다.
3. 저장합니다.
4. 이 ZIP의 파일들을 GitHub MealLogAI main에 덮어씁니다.
5. Vercel 배포 완료 후 Ctrl+F5 합니다.
6. 상단 로그인 버튼에서 회원가입 -> 이메일 인증 -> 로그인합니다.

주의: Secret key / service_role key는 절대 넣지 마세요. Publishable key만 사용합니다.
기존 localStorage 기록은 지우지 않으며, 첫 로그인 시 클라우드 기록과 합쳐 동기화합니다.
