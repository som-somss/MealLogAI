MealLogAI FoodDB v6

1. 이 폴더의 파일들을 GitHub MealLogAI 저장소에 업로드합니다.
2. Commit directly to the main branch 를 선택합니다.
3. Commit changes 를 누릅니다.
4. Vercel Production 배포가 완료되면 앱을 새로고침합니다.

중요:
- 이 배포본에는 supabase-config.js가 의도적으로 들어있지 않습니다.
- 따라서 현재 GitHub에 저장된 Supabase Publishable key를 덮어쓰지 않습니다.

v6 변경:
- 음식 DB 대폭 확장 (김밥 세부 종류, 한식/분식/면/고기/해산물/카페/간식 등)
- 검색 결과 최대 20개
- 음식별 1줄/1인분/1개/100g 등 섭취량 선택 및 영양 자동 계산
- 음식 기록창 '취소' 버튼 모바일 터치 수정
- 기록창 상단 취소/저장 버튼을 스크롤 중에도 고정
- 배경 영역 탭으로도 기록창 닫기 지원

영양정보는 일반적인 조리 예시를 바탕으로 한 대략적인 값이며 제품/레시피에 따라 달라질 수 있습니다.
